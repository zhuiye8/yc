# 页面数据来源说明

> 数据来源说明
>
> - **假数据**：前端静态示例数据，不来自任何接口
> - **WF接口**：WF数据提供的远程接口
> - **研究院接口**：研究院提供的远程接口
> - **本地缓存库**：预先整理好的本地数据库
> - **研究院接口 + 假比例**：总数真实，但细项按固定比例分配（非真实明细）

## 汇总说明

| 数据来源 | 涉及模块 |
|---------|---------|
| **研究院接口（真实）** | 人才引育全部、产业招引中的人才、创新资源地图/趋势/列表、人才详情页、大屏人才/产业搜索 |

# 人才库接口清单

## 1. 说明

本文里的 JSON 字段状态统一分为 3 类：

- `json中有且有有效值`
- `json中有但没有有效值`
- `json中没有`

---

- `CNAME`
- `AORG`
- `PROVINCE`
- `CITY`
- `ORGTYPE`

## 4. 逐接口说明

## 4.1 人才搜索接口

### 对应页面

- 人才图谱页
- 产业页顶部搜索抽屉
- 产业链节点人才抽屉
- 产业链整链人才聚合
- 产业大屏右侧链上人才
- 人才大屏里的宜昌产业链人才数

### 请求参数

| 参数 | 必须/可选 | 为什么需要 |
| --- | --- | --- |
| `keyword` | 必须 | 所有搜索入口都要按关键词查人才 |
| `page` 或 `from` | 必须 | 列表分页 |
| `pageSize` 或 `size` | 必须 | 列表分页 |
| `city` | 必须 | 当前代码里要区分全国和宜昌 |
| `province` | 可选 | 后续做更大范围筛选时需要 |
| `sort` | 可选 | 如果要按 H 指数、成果数排序会用到 |

### 响应字段

| 字段 | 必须/可选 | 为什么需要 | JSON情况 |
| --- | --- | --- | --- |
| `total` | 必须 | 页面要显示总数和分页，必须是精确值 | `json中没有` |
| `items[].ID` | 必须 | 人才唯一标识，列表跳转详情、去重都要用 | `json中有且有有效值` |
| `items[].CNAME` | 必须 | 姓名展示 | `json中有且有有效值` |
| `items[].AORG` | 必须 | 所属机构展示 | `json中有且有有效值` |
| `items[].TITLE` | 必须 | 列表和卡片都要显示职称 | `json中有但没有有效值` |
| `items[].H` | 必须 | 排序、等级判断、卡片展示要用 | `json中有但没有有效值` |
| `items[].DIRECTION` | 建议必须 | 当前人才卡要展示研究方向 | `json中有但没有有效值` |
| `items[].CATE` | 建议必须 | 学科领域展示 | `json中有但没有有效值` |
| `items[].QIKAN` | 必须 | 论文数展示 | `json中没有` |
| `items[].ZHUANLI` | 必须 | 专利数展示 | `json中没有` |
| `items[].CHENGGUO` | 必须 | 成果数展示 | `json中没有` |
| `items[].CHANXUEYANHZ` | 可选 | 产业页人才抽屉展示合作次数 | `json中没有` |
| `items[].PROVINCE` | 建议必须 | 区域展示/筛选 | `json中有且有有效值` |
| `items[].CITY` | 建议必须 | 区域展示/筛选 | `json中有且有有效值` |
| `items[].ORGTYPE` | 可选 | 机构类型展示 | `json中有且有有效值` |
| `items[].TAGLARG` | 可选 | 标签展示，可补充领域信息 | `json中有且有有效值` |
| `items[].PHOTOPATH` | 可选 | 如果列表需要头像可以直接复用 | `json中有但没有有效值` |

### 必须要有

- `total`
- `ID`
- `CNAME`
- `AORG`
- `TITLE`
- `H`
- `QIKAN`
- `ZHUANLI`
- `CHENGGUO`

### 字段补充说明

- `total`：列表分页和总数展示必须依赖精确值。
- `ID`：详情跳转、列表去重、图谱关系都要用主键。
- `CNAME`、`AORG`：所有列表最基础的展示字段。
- `TITLE`：当前多个页面直接展示职称。
- `H`：当前代码用 H 指数做排序和等级判断。
- `QIKAN`、`ZHUANLI`、`CHENGGUO`：当前页面直接展示论文、专利、成果三项统计。

### 可以先没有

- `CHANXUEYANHZ`
- `ORGTYPE`
- `TAGLARG`
- `PHOTOPATH`

## 5. 优先级说明
